# Exercise 20: Full Web Server Deployment

## Learning Objectives

- Deploy a complete web application stack
- Combine all learned concepts
- Implement best practices
- Create a production-ready playbook

## Prerequisites

- Completed Exercises 1-19
- Understanding of all previous concepts

## Project Overview

Deploy a complete web application with:
- Nginx web server
- Application backend
- Database
- Monitoring
- Logging
- Security configurations

## Steps

### Step 1: Project Structure

Create the project structure:

```bash
# Create project directory
mkdir -p /tmp/web-deployment/{roles,group_vars,host_vars,files,templates}
cd /tmp/web-deployment

# Create roles structure
mkdir -p roles/{common,nginx,application,database,monitoring}/{tasks,handlers,templates,files,vars,defaults,meta}
```

### Step 3: Create Nginx Role

```bash
# Nginx tasks
cat > roles/nginx/tasks/main.yml << 'EOF'
---
- name: Install Nginx (simulated)
  debug:
    msg: "Installing Nginx..."
  tags:
    - nginx
    - install

- name: Create Nginx directories
  file:
    path: "{{ item }}"
    state: directory
  loop:
    - "{{ nginx_conf_dir }}"
    - "{{ nginx_sites_available }}"
    - "{{ nginx_sites_enabled }}"
    - "{{ nginx_log_dir }}"
  tags: nginx

- name: Deploy Nginx configuration
  template:
    src: nginx.conf.j2
    dest: "{{ nginx_conf_dir }}/nginx.conf"
    validate: 'grep -q "worker_processes" %s'
  notify: reload nginx
  tags:
    - nginx
    - config

- name: Deploy site configuration
  template:
    src: site.conf.j2
    dest: "{{ nginx_sites_available }}/{{ app_name }}.conf"
  notify: reload nginx
  tags:
    - nginx
    - config

- name: Enable site
  file:
    src: "{{ nginx_sites_available }}/{{ app_name }}.conf"
    dest: "{{ nginx_sites_enabled }}/{{ app_name }}.conf"
    state: link
  notify: reload nginx
  tags: nginx

- name: Deploy SSL certificates (simulated)
  copy:
    content: |
      -----BEGIN CERTIFICATE-----
      (Simulated SSL Certificate)
      -----END CERTIFICATE-----
    dest: "{{ nginx_ssl_cert }}"
  when: enable_ssl
  tags:
    - nginx
    - ssl

- name: Start Nginx (simulated)
  debug:
    msg: "Starting Nginx..."
  tags: nginx
EOF

# Nginx handlers
cat > roles/nginx/handlers/main.yml << 'EOF'
---
- name: reload nginx
  debug:
    msg: "Reloading Nginx configuration"

- name: restart nginx
  debug:
    msg: "Restarting Nginx"
EOF

# Nginx templates
cat > roles/nginx/templates/nginx.conf.j2 << 'EOF'
# Nginx Main Configuration
# Generated by Ansible

user {{ nginx_user }};
worker_processes {{ nginx_worker_processes }};
pid {{ nginx_pid_file }};

events {
    worker_connections {{ nginx_worker_connections }};
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # Logging
    access_log {{ nginx_log_dir }}/access.log;
    error_log {{ nginx_log_dir }}/error.log {{ nginx_error_log_level }};

    # Performance
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout {{ nginx_keepalive_timeout }};

    # Gzip
    gzip on;
    gzip_vary on;
    gzip_types text/plain text/css application/json application/javascript;

    # Include site configurations
    include {{ nginx_sites_enabled }}/*.conf;
}
EOF

cat > roles/nginx/templates/site.conf.j2 << 'EOF'
# {{ app_name }} Site Configuration

{% if enable_ssl %}
server {
    listen 80;
    server_name {{ server_name }};
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name {{ server_name }};

    ssl_certificate {{ nginx_ssl_cert }};
    ssl_certificate_key {{ nginx_ssl_key }};
{% else %}
server {
    listen {{ http_port }};
    server_name {{ server_name }};
{% endif %}

    root {{ app_root }}/public;
    index index.html index.htm;

    # Logging
    access_log {{ nginx_log_dir }}/{{ app_name }}-access.log;
    error_log {{ nginx_log_dir }}/{{ app_name }}-error.log;

    # Static files
    location /static {
        alias {{ app_root }}/static;
        expires 30d;
    }

    # API proxy
    location /api {
        proxy_pass http://127.0.0.1:{{ app_port }};
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Health check endpoint
    location /health {
        access_log off;
        return 200 "healthy\n";
    }
}
EOF

# Nginx defaults
cat > roles/nginx/defaults/main.yml << 'EOF'
---
```

### Step 4: Create Application Role

```bash

app = Flask(__name__)

# Configuration

@app.route('/api/health')
def health():
    return jsonify({
        'status': 'healthy',
        'version': '{{ app_version }}',
        'environment': '{{ app_environment }}'

        'environment': '{{ app_environment }}',
        'database': '{{ db_host }}:{{ db_port }}',

    app.run(host=HOST, port=PORT, debug=DEBUG)
```

```bash
{% endfor %}

email = {{ monitoring_alert_email }}

[metrics]
collection_interval = {{ monitoring_collection_interval }}
retention_days = {{ monitoring_retention_days }}
EOF

cat > roles/monitoring/templates/healthcheck.sh.j2 << 'EOF'
#!/bin/bash
# Health Check Script for {{ app_name }}

check_service() {
    local service=$1
    local url=$2
    local response=$(curl -s -o /dev/null -w "%{http_code}" $url 2>/dev/null || echo "000")
    
    if [ "$response" = "200" ]; then
        echo "✓ $service is healthy (HTTP $response)"
        return 0
    else
        echo "✗ $service is unhealthy (HTTP $response)"
        return 1
    fi
}

echo "=== Health Check Report ==="
echo "Timestamp: $(date)"
echo ""

# Check web server
check_service "Web Server" "http://localhost:{{ http_port }}/health"

# Check application
check_service "Application" "http://localhost:{{ app_port }}/api/health"

# Check database (simulated)
echo "✓ Database is healthy"

echo ""
echo "Health check completed"
EOF
```

### Step 7: Create Main Playbook

```bash
cat > site.yml << 'EOF'
---
- name: Complete Web Application Deployment
  hosts: all
  become: no
  gather_facts: yes
  
  vars:
    deployment_id: "{{ 99999 | random | to_uuid }}"
    deployment_timestamp: "{{ ansible_date_time.iso8601 }}"
  
  pre_tasks:
    - name: Display deployment information
      debug:
        msg: |
          ╔══════════════════════════════════════════════╗
          ║   WEB APPLICATION DEPLOYMENT                 ║
          ╠══════════════════════════════════════════════╣
          ║ Deployment ID: {{ deployment_id[:8] }}...   ║
          ║ Timestamp: {{ deployment_timestamp }}       ║
          ║ Environment: {{ app_environment }}           ║
          ║ Version: {{ app_version }}                   ║
          ╚══════════════════════════════════════════════╝
      tags: always
    
    - name: Verify prerequisites
      assert:
        that:
          - app_name is defined
          - app_version is defined
          - app_environment in ['development', 'staging', 'production']
        fail_msg: "Missing required variables"
        success_msg: "Prerequisites verified"
      tags: always
  
  roles:
    - role: common
      tags: common
    
    - role: database
      tags: database
    
    - role: application
      tags: application
    
    - role: nginx
```

## Troubleshooting

### Problem: Deployment fails

**Solution:** Check specific role
```bash
ansible-playbook site.yml --tags database -v
```

### Problem: Configuration not applying

**Solution:** Force handlers
```bash
ansible-playbook site.yml --flush-cache
```

### Problem: Variables not loading

**Solution:** Debug variables
```bash
ansible-playbook site.yml --tags debug -e "debug_vars=true"
```
